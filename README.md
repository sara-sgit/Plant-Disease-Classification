# 🌱 PlantAI - Tomato Disease Classification System

PlantAI is an intelligent system that **classifies tomato plant diseases from uploaded leaf images** using advanced deep learning techniques. The system analyzes leaf patterns and symptoms to identify diseases.

<img width="500" alt="Tomato Disease Classification System" src="https://github.com/sara-sgit/Plant-Disease-Classification/blob/main/Home.PNG" />



## ✨ Key Features

### 🔍 Automated Disease Classification
- Upload a tomato leaf image and get instant disease diagnosis
- Covers 9 common tomato diseases + healthy plants
- Detailed symptom information for each disease

### 🔬 **Prediction Protocols**

**Two distinct approaches for disease classification:**

**Protocol 1: Selection → Fusion**  
   - Performs feature selection on each model individually  
   - Combines selected features for final classification  


**Protocol 2: Fusion → Selection**  
   - Combines all model features first  
   - Then applies feature selection
